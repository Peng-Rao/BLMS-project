Yacht hydrodynamic resistance

Source. UCI Machine Learning Repository, https://archive.ics.uci.edu/dataset/243/yacht+hydrodynamics. Original record: Gerritsma, Onnink and Versluis, Geometry, resistance and stability of the Delft Systematic Yacht Hull Series, 1981.

Data. The dataset describes 22 different hull forms (sailing yacht), each tested at multiple Froude numbers in a towing tank, producing 308 hull-form ×× Froude-number rows.

Variables:

LCB : longitudinal position of the center of buoyancy (% length).

prismatic : prismatic coefficient (dimensionless).

L_disp : length-displacement ratio.

beam_draught : beam-draught ratio.

L_beam : length-beam ratio.

Froude : Froude number (dimensionless, Fn=v/gL−−√Fn=v/gL), in [0.125, 0.45]. The dominant predictor.

resistance : residuary resistance per unit weight of displacement (target variable).

Task. The physics of the problem says that for sailing yachts the residuary resistance follows a power law of the Froude number with exponent close to 4 in the bulk regime. A good Bayesian project explores this:

  1. Log-log regression. Fit

    log(resistance)=β0+βFlog(Froude)+∑kβkhullk+ε.log⁡(resistance)=β0+βFlog⁡(Froude)+∑kβkhullk+ε.
    Verify that β^F≈4β^F≈4.

  2. BAS / BMA. Use bas.lm to enumerate the 2525 submodels over the five hull-geometry covariates and identify which of them (LCB, prismatic, L/disp, B/draught, L/beam) carry signal once Froude is in the model.

  3. Correct for heteroscedasticity. Train the nonlinear model

    resistance=kFroudeγFexp{∑kβkhullk}+εresistance=kFroudeγFexp⁡{∑kβkhullk}+ε
    where only the form factors that appear relevant in the model selection phase are kept for the nonlinear modelling. Compare the results with the log-log regression and discuss the impact of the heteroscedasticity correction on the inference on γFγF and on the hull-geometry covariates.

  4. Plot the posterior predictive curves and compare the curves with or without the treatment of the heteroscedasticity and compare the curves with the data.

1. Log-log regression (Bayesian, reference prior)

We fit the log-log model

log(resistance)=β0+βFlog(Froude)+∑k=15βkhullk+ε,ε∼N(0,σ2),log⁡(resistance)=β0+βFlog⁡(Froude)+∑k=15βkhullk+ε,ε∼N(0,σ2),
with the non-informative reference (Jeffreys) prior π(β∣σ2)∝1π(β∣σ2)∝1, π(σ2)∝1/σ2π(σ2)∝1/σ2. The smallest resistance is 0.01>00.01>0, so the logarithm is well defined and no offset is needed. Under this prior the marginal posterior of each coefficient is a Student-tt centred at the OLS estimate β^β^, and the posterior credible intervals are numerically identical to the OLS confidence intervals. We can therefore read the full Bayesian inference straight off lm(): point estimates from coef(), 95% credible intervals from confint(), and any posterior probability (such as P(βF>4)P(βF>4)) from the Student-tt. The goal is to verify the physical expectation βF≈4βF≈4.

set.seed(2026)

The residuals show a ∪∪-shaped curvature (the local Froude exponent grows with speed) and a variance that shrinks as the fitted value grows (heteroscedasticity). Both defects motivate the heteroscedasticity-corrected nonlinear model of parts 3-4.

2. BAS / BMA model selection over hull covariates

The first model already shows the main physical effect: log_Fr is overwhelmingly important. The second question is more subtle: after Froude is already in the model, do any of the five hull-geometry variables still add useful information?

We answer this with Bayesian Adaptive Sampling / Bayesian Model Averaging. In this project the model space is small: there are five optional hull covariates, so there are only 25=3225=32 possible submodels. We keep log_Fr in every model and let bas.lm enumerate every combination of

LCB, prismatic, L_disp, beam_draught, and L_beam.

The key output is the posterior inclusion probability (PIP): the posterior probability that a variable belongs in the regression model. A PIP near 1 means strong evidence that the variable carries signal; a PIP near 0.5 is weak/ambiguous; a small PIP means little evidence once the other variables and Froude are considered.

if (!requireNamespace("BAS", quietly = TRUE)) {
  stop("Package 'BAS' is required. Install it with install.packages('BAS') before knitting.")
}
library(BAS)

# Optional hull-geometry covariates. These are the five variables requested in the project.
hull_covariates <- c("LCB", "prismatic", "L_disp", "beam_draught", "L_beam")

# Sanity check: fail loudly if a requested covariate is missing or misspelled.
stopifnot(all(c("log_res", "log_Fr", hull_covariates) %in% names(yh)))

# In the model-selection step, log_Fr must be present in every model.
# The five hull covariates are optional, so bas.lm enumerates 2^5 = 32 submodels.
bas_fit <- bas.lm(
  log_res ~ log_Fr + LCB + prismatic + L_disp + beam_draught + L_beam,
  data = yh,
  prior = "BIC",
  modelprior = uniform(),
  method = "deterministic",
  n.models = 2^length(hull_covariates),
  include.always = ~ log_Fr,
  force.heredity = FALSE
)

# Check that the model space has really been fully enumerated.
n_models_expected <- 2^length(hull_covariates)
n_models_observed <- length(bas_fit$postprobs)
cat("Number of models enumerated:", n_models_observed, "\n")
## Number of models enumerated: 32
stopifnot(n_models_observed == n_models_expected)

# BAS may store the selected variables either as a list of indices or as a matrix,
# depending on the package version. The following code converts both cases into
# a stable 0/1 model-inclusion matrix.
term_names <- c("(Intercept)", "log_Fr", hull_covariates)

make_which_matrix <- function(which_obj, term_names) {
  if (is.list(which_obj) && !is.matrix(which_obj)) {
    out <- t(sapply(which_obj, function(idx) {
      # BAS indexes terms from 0: 0 = intercept, 1 = log_Fr, 2:6 = hull covariates.
      as.integer((seq_along(term_names) - 1) %in% idx)
    }))
    colnames(out) <- term_names
    return(out)
  }

  out <- as.matrix(which_obj)
  if (ncol(out) == length(term_names)) {
    colnames(out) <- term_names
  } else if (ncol(out) == length(term_names) - 1) {
    colnames(out) <- term_names[-1]
  } else {
    stop("Unexpected format for bas_fit$which. Inspect str(bas_fit$which).")
  }
  out
}

model_matrix <- as.data.frame(make_which_matrix(bas_fit$which, term_names))

# Normalise posterior model probabilities and attach them to the model matrix.
post_prob <- bas_fit$postprobs / sum(bas_fit$postprobs)
model_matrix$post_prob <- post_prob

# Check that log_Fr is indeed included in all models and that the five hull terms exist.
stopifnot(all(model_matrix$log_Fr == 1))
stopifnot(all(hull_covariates %in% names(model_matrix)))

# Posterior inclusion probabilities computed directly from the enumerated models.
# This avoids relying on version-dependent names in bas_fit$probne0.
pip_hull <- sapply(hull_covariates, function(v) {
  sum(model_matrix[[v]] * model_matrix$post_prob)
})

pip_sorted <- sort(pip_hull, decreasing = TRUE)
pip_table <- data.frame(
  covariate = names(pip_sorted),
  PIP = round(as.numeric(pip_sorted), 3),
  evidence = ifelse(pip_sorted >= 0.75, "strong",

Conclusion of part 2. The BAS/BMA step does not find strong evidence for any single hull-geometry covariate once Froude is included. The clearest answer to the model-selection question is that B/draught (beam_draught) is the only hull covariate that carries moderate signal, with PIP about 0.565 in the rendered output. The remaining variables – LCB, prismatic, L_disp (L/disp), and L_beam (L/beam) – have weak posterior inclusion probabilities, all below 0.50. Therefore, the defensible conclusion is: the dominant signal is the Froude power law; hull geometry may have small secondary effects, but the data do not strongly identify a stable subset of hull covariates in the homoscedastic log-log model.

This is consistent with part 1: in the full log-log regression, all five hull coefficients had 95% intervals crossing zero. BAS/BMA provides additional evidence that this is not just a single-model artefact; across the whole 2525 model space, no hull variable receives overwhelming posterior support.

For parts 3 and 4, this gives a clear continuation point. The nonlinear heteroscedasticity-corrected model should carry forward B/draught (beam_draught) as the main reduced hull-geometry candidate, and it is also reasonable to compare it with a no-hull version as a sensitivity check, because the BAS evidence for hull effects is moderate rather than strong.
